# SIPGNHELPER Platform

Fullstack Data Management & Automation Platform.

## Quick Start

### 1. Backend Service
```bash
cd backend
npm install
npm run dev
```
Backend runs on `http://localhost:5001`.

### 2. Frontend Application
```bash
cd frontend
npm install
npm run dev
```
Frontend runs on `http://localhost:5000`.

## Architecture
- **Backend**: Express + Node.js + TypeScript
- **Frontend**: React + Vite + TypeScript + Custom Glassmorphism Theme
